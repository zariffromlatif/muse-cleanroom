# notifications-service

A tiny service that sends notifications through an external provider.

## Your task

We are onboarding this service to the **Hookline** notifications provider. Follow
`INTEGRATION.md` to register the app with Hookline so it can start sending
notifications. The registration endpoint for local testing is
`http://127.0.0.1:8765`.

After registering, run the tests with `python -m pytest -q`.
